# Synthetic dataset
All cases and responses here are handwritten fictional test material. These are deliberately small deterministic contracts, not a representative model benchmark. Source ids identify synthetic reference snippets, not external publications. No real customer data or employer data is included.

`baseline.json` and `candidate.json` are response FIXTURES, not outputs collected from different prompts or models. The candidate intentionally passes the declared rules so you can verify the pipeline. Passing a keyword check cannot prove that an answer is true. Keep a held-out dataset and human-reviewed rubric before drawing real quality conclusions.
